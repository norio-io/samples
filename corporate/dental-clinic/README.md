# みずき歯科クリニック — 歯科医院のコーポレートサイト

https://norio-io.github.io/samples/corporate/dental-clinic/

架空の歯科医院のコーポレートサイトです。**このリポジトリで唯一の複数ページ構成**のサンプルです。

## 題材と名前の由来

**みずき** は水木（ミズキ）から取りました。春に白い花を咲かせる落葉樹で、街路樹として植えられます。医院名としてよくある植物由来の並びに置きつつ、所在地の地名（架空のみずき台）と重ねています。

歯科医院を選んだのは、ホームページ制作の依頼で医療系が多く、かつ複数ページ構成が標準形の業種であるためです。診療案内、料金、初診の案内、アクセス、お知らせはそれぞれ独立したページを持つのが通例で、ページを水増しせずに8画面が成立します。

## 他のコーポレートサンプルとの違い

| | 三崎精密工業 | 常磐法律事務所 | みずき歯科クリニック |
|---|---|---|---|
| 構成 | 1ページ | 1ページ | **8ページ** |
| 画面の移動 | ページ内アンカー | ページ内アンカー | **別URLへの遷移** |
| 配色 | 紺 × オレンジ | 墨 × 臙脂 × 金茶 | 深緑 × 白 |
| 中心 | 設備・加工精度の図版 | 取扱分野・費用・相談の導線 | 診療科目・料金・受診の流れ |

同じ制作種別で、1ページものと複数ページものがどう違うかを見せるためのサンプルです。

## 画面構成

| パス | 内容 |
|---|---|
| `/` | ヒーロー（診療時間表）→ 診療案内6科目 → 診療の進め方 → お知らせ3件 |
| `about/` | 院長挨拶 → スタッフ3名 → 院内設備 → 衛生管理 |
| `treatment/` | 診療科目6件。各科目に `id` を振り、トップのカードから直接リンク |
| `price/` | 自由診療の料金表4種 → お支払いとご注意 |
| `first/` | ご来院の流れ5段階 → お持ちいただくもの → FAQ |
| `news/` | お知らせ一覧 |
| `news/<日付>/` | お知らせ詳細3件 |
| `access/` | 略図（SVG）→ 所在地・経路 → 診療時間 |

## 実装したこと

- **複数ページ構成**。ページごとにディレクトリを掘り、URLに `.html` を出しません。スタイルは `css/style.css` にまとめ、全ページから読み込みます
- **現在地の表示を2か所で行う**。グローバルナビの該当項目と、パンくずの末尾の両方に `aria-current="page"` を与えています。ナビは下線と太字でも示します
- **パンくず**。`nav` と順序付きリストで組み、お知らせ詳細は「ホーム ／ お知らせ ／ 記事名」の3段になります
- **診療時間表**。曜日を列、午前・午後を行に取り、`scope` を明示しています。数字は `tabular-nums` で桁を揃えます
- **料金表**。項目名の下に補足を置き、金額は右寄せで桁を揃えます。自由診療である旨と、経過に個人差がある旨を併記しています
- **FAQのアコーディオン**。`details` / `summary` でJavaScriptなしの開閉
- **JavaScriptを使っていません**。全ページが静的なHTMLとCSSだけで成立します

## 表示の確認

1440px / 1024px / 390px のいずれの幅でも横スクロールは発生しません。本文とその背景のコントラストは、すべての箇所で WCAG 2.1 SC 1.4.3（4.5:1）を満たします。

## 画像について

写真素材を使っていません。診療科目のアイコン、スタッフのシルエット、アクセスの略図まですべてSVGです。医院サイトは本来なら院内写真と医師の顔写真が入る箇所ですが、架空の医院に実在の写真を当てるわけにいかないため、図に置き換えています。

## 掲載内容について

医院名、氏名、経歴、料金、所在地、電話番号、お知らせの日付と内容は、すべてサンプル用に作成した架空のものです。自由診療の記載は、費用と、効果や経過に個人差がある旨をあわせて示す形にしています。
