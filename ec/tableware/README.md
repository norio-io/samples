# 灯し器 — うつわのオンラインストア

https://norio-io.github.io/samples/ec/tableware/

架空のうつわ店のECサイトです。一覧・商品詳細・カートを1ファイルで実装しています。

## 題材と名前の由来

**灯し器**（ともしき）は、「灯し」と「器」を掛けた造語です。明かりを灯す道具と、食卓の器の両方を指します。

## 実装したこと

- **一覧の絞り込みと並び替え**
- **色のバリエーション選択と在庫表示**。在庫が残り1点の商品では数量の「＋」ボタンが無効になります
- **カート**。数量変更、送料計算、`localStorage` による再訪時の保持（バージョン付きキー、`try`/`catch` で保護）
- **History API による画面遷移**。`pushState` / `popstate` で一覧・詳細・カートのURLを同期させています。商品詳細は `?item=p3`、カートは `?view=cart`。ブラウザの戻るボタンで一覧に戻り、URLを直接開いても該当画面が表示されます

サーバーを持たない静的ページなので、実際の決済処理は行いません。
