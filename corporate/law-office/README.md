# 常磐法律事務所 — 法律事務所のコーポレートサイト

https://norio-io.github.io/samples/corporate/law-office/

架空の法律事務所のコーポレートサイトです。

## 題材と名前の由来

**常磐（ときわ）** は常磐木、つまり常緑樹から取りました。葉を落とさず変わらずそこにある、という含意です。法律事務所は「同じ場所で長く続けていること」自体が信用の材料になるため、そこを名前に置きました。

コーポレートサイトの2本目として士業を選んだのは、同じ「コーポレートサイト」でも、製造業とは必要なものがまったく違うためです。製造業は設備と加工精度を見せますが、士業は扱う分野、担当者、費用、相談までの導線を見せます。

## 三崎精密工業のサンプルとの違い

| | 三崎精密工業 | 常磐法律事務所 |
|---|---|---|
| 書体 | ゴシック | **明朝**（Hiragino Mincho ProN / Yu Mincho） |
| 配色 | 紺 × オレンジ | 墨 × 臙脂 × 金茶 |
| 中心 | 設備・加工精度の図版 | 取扱分野・費用・相談の導線 |
| 構成 | 図版と余白 | 表組みと罫線 |

同じ制作種別で、業種によって設計がどう変わるかを見せるための2本目です。

## 画面構成

ヒーロー → 取扱分野（4分野）→ 三つのお約束 → 弁護士紹介 → ご相談の流れ → 費用 → 取り扱った事案 → FAQ → 事務所概要・問い合わせフォーム。

## 実装したこと

- **本文を明朝で組む**。見出しと事務所名に明朝、本文とラベルにゴシックを当てています。外部フォントは読み込まず、macOSとWindowsの標準搭載フォントだけで成立させました
- **費用を表で出す**。士業サイトで最も見られる箇所なので、目安の金額と、実費が別途かかる旨を明記しています
- **入力チェック付きの問い合わせフォーム**。氏名、メール形式、電話番号（ハイフンなし9〜11桁。固定電話を想定）、相談分野、相談内容、同意チェックを検証します
- **FAQのアコーディオン**。`details` / `summary` でJavaScriptなしの開閉
- **スクロールに応じた表示演出**（`IntersectionObserver` / `prefers-reduced-motion` 対応）

## 画像について

写真素材を使っていません。天秤、アイコン、弁護士のシルエットまですべてSVGです。士業サイトは本来なら顔写真が入る箇所ですが、架空の人物に実在の顔写真を当てるわけにいかないため、シルエットに置き換えています。
