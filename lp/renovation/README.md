# かなえ住まい工房 — リフォーム会社の無料見積もりランディングページ

https://norio-io.github.io/samples/lp/renovation/

架空のリフォーム会社「かなえ住まい工房」の、無料見積もりの申し込みへ誘導するランディングページです。想定する閲覧者は、築20年前後の戸建てに住み、水回りや内装の改修を検討している世帯です。

## 題材と名前の由来

**かなえ住まい工房** は「住まいの希望をかなえる」の意です。「工房」には、自社の職人が手を動かす会社であることを込めています。

リフォームのランディングページは、施工事例で仕上がりを示し、費用の目安で不安を取り除き、無料見積もりへの申し込みにつなげる構成が標準形です。本サンプルはこの構成に沿っています。

配色は、白木を思わせる生成（`#f4ecdc`）の地に、墨（`#1f1e1c`）の文字と朱（`#b83a1c`）の差し色を置きました。見出しの印は大工道具の曲尺（さしがね）、罫は墨壺の糸を模しています。角丸と影は使わず、罫線と面の切り替えで区画を分けています。

## 画面構成

第一画面（キャッチコピー、費用の目安の最低額、無料見積もりの導線）→ よくある悩み → 施工事例4件 → 費用の目安 → 工事の流れ → お客様の声3件 → 無料見積もりの申し込みフォーム、の縦1枚です。

## 実装したこと

- **施工前と施工後の比較**。同じ構図で描いた施工前と施工後の SVG を重ね、`clip-path` で施工前の表示幅を切り替えます。操作部は `<input type="range">` で、ドラッグ、クリック、キーボード（左右キーで5%ずつ、Shift を押しながらで1%ずつ、Home / End で端）で動かせます。`aria-valuetext` に「施工前 40%、施工後 60%」の形で位置を入れ、読み上げに伝えます
- **工事ごとの費用の目安の表**。キッチン、浴室、トイレ、内装について、価格帯、工期、含まれる工事、価格の条件を示します。`table-layout: fixed` と列幅の指定で幅を内容に依存させず、スマートフォン幅では1工事1枚のカード状に組み替えます
- **入力の検証つきの申し込みフォーム**。工事の種類（複数選択）、都道府県、希望時期、氏名、電話番号、メールアドレス、同意を検証し、未入力と書式の誤りを、それぞれ該当する入力欄の直下に文章で示します。`aria-invalid` と `aria-describedby` でエラーを入力欄に結び付け、最初のエラー項目にフォーカスを移します。電話番号は全角数字とハイフンを許容します。送信処理は持ちません
- **画面下部に固定した申し込みの導線**。`IntersectionObserver` で第一画面とフォームの区画を監視し、第一画面を過ぎてからフォームに達するまでの間だけ表示します。隠している間は `visibility: hidden` とし、キーボードの移動先に含めません

## 画像について

写真は使っていません。第一画面の家の断面図と、施工事例8枚（4件の施工前と施工後）は、すべてインラインの SVG で描いています。施工事例は、施工前と施工後で窓や収納の位置を揃え、変わった部分だけが比べられるようにしています。

掲載している金額、施工事例、お客様の声、連絡先はすべて架空です。
