# ひととせ整体院 — 整体院の店舗サイト

https://norio-io.github.io/samples/store/bodywork/

架空の整体院の店舗サイトです。整体院、美容室、エステなどの小規模な店舗で標準形になっている、「施術メニューと料金」「初めての方への案内」「予約の導線」を中心にした構成を、複数ページで組んでいます。

## 題材と名前の由来

**ひととせ** は「一年」を意味する古い言葉です。季節がひとめぐりするあいだ、無理なく通い続けられる場所でありたい、という意味を込めました。ロゴは円を四つの弧に分け、四季をめぐる一年を表しています。

想定する閲覧者は、肩や腰の不調を抱え、初めて整体院を探している社会人です。料金がいくらか、初回に何をされるのか、どう予約するのかを、短時間で確かめられることを優先しました。

## 麦と焙煎（同じ店舗サイト）との違い

| | 麦と焙煎 | ひととせ整体院 |
|---|---|---|
| 構成 | 1ページ | **5ページ** |
| 中心 | 店の雰囲気と商品 | 料金・初回の流れ・予約の導線 |
| 配色 | 2案を切り替え | 灰青 × 杏 |
| JavaScript | デザインの切り替え | 本日の営業、予約フォームの検証 |

## 画面構成

| パス | 内容 |
|---|---|
| `/` | キャッチコピーと予約の導線（本日の営業）→ こんな悩みの方へ → 施術の特長 → メニューの抜粋 → 施術者の紹介 → 店舗の案内（店内のイラスト、営業時間表） |
| `menu/` | 料金表（所要時間・通常料金・初回料金）→ 各メニューの内容 → 回数券 |
| `first/` | 来店から施術後までの流れ5段階 → 持ち物と服装 → よくある質問 |
| `access/` | 略図（SVG）→ 所在地・駐車場・駐輪場・経路 → 営業時間表 |
| `reserve/` | Web予約の入力フォーム（入力の検証のみ。送信しません） |

## 実装したこと

- **料金表の桁揃え**。`table-layout: fixed` と em 単位の列幅で表の幅を内容に依存させず、数字は `tabular-nums` と右寄せで全行の桁位置を揃えています。初回料金の列は杏の淡い地で通常料金の隣に置き、割引後の料金を見比べられるようにしています
- **本日の曜日の強調**。営業時間表は曜日を列、時間帯（午前・午後・夜）を行に取り、`scope` を明示しています。列見出しに `data-day`（`Date#getDay()` の値）を持たせ、JavaScript が本日の列の見出しとセルに `.is-today` を付け、見出しに「本日」と書き足します。トップの「本日の営業」には、曜日に応じた営業時間（水曜は定休日の案内）を表示します。確認用に `?today=2026-10-07` のように日付を差し替えられます
- **予約の導線を同じ位置に置く**。広い画面ではヘッダーの右端に電話番号と「Web予約」、幅 760px 以下では画面下部に「電話する」「Web予約」の固定バーを置きます。どのページでも同じ位置です。ヘッダーは `position: sticky`（`z-index: 20`）、固定バーはそれより小さい `z-index: 10` としています
- **よくある質問の開閉**。`details` / `summary` でJavaScriptなしに開閉し、キーボードでも操作できます。開閉の状態は「＋」「−」の印で示します
- **予約フォームの検証**。必須項目、電話番号の形式、定休日（水曜）の除外、60日先までの上限、土日の受付時刻を検証します。誤りは項目ごとに `aria-invalid` と `aria-describedby` で結び付け、フォームの冒頭に一覧を出して各項目へ移動できるようにしています。送信処理は持ちません
- **現在地の表示**。グローバルナビの該当項目とパンくずの末尾に `aria-current="page"` を与えています
- **文字の大きさは body を基準とした em**。body の文字サイズを変えても、表や見出しが同じ比率で大きくなります

## 配色

| 役割 | 色 | 用途とコントラスト |
|---|---|---|
| 灰青 | `#4b6676` | 基調。白地の文字で 6.07:1 |
| 灰青（濃） | `#33495a` | リンク、見出しの補助 |
| 杏 | `#eda56b` | 予約ボタン、本日の列の見出し。上に置く文字は `#1e2a32` で 7.12:1 |
| 杏（文字用） | `#94501d` | 初回料金、必須の印。白地で 6.13:1 |
| 杏（淡） | `#fbeee2` | 初回料金の列、本日の列 |

写真の代わりのグラデーション背景、絵文字のアイコン、全要素に均一な角丸と影は使っていません。角は原則として直角にし、区切りは罫線で示します。

## 画像について

写真素材を使っていません。施術者2名と店内、アクセスの略図、特長のアイコンはすべてインラインのSVGです。

## 掲載内容について

店舗名、氏名、経歴、料金、所在地、電話番号は、すべてサンプル用に作成した架空のものです。施術は医療行為ではない旨と、効果の感じ方に個人差がある旨を併記しています。
