# スタジオ白日 — レンタル撮影スタジオの予約サイト

https://norio-io.github.io/samples/booking/photo-studio/

架空のレンタル撮影スタジオの予約サイトです。空き状況の確認から予約の完了までを、1ファイルのSPAとして実装しています。

## 題材と名前の由来

**白日（はくじつ）** は、撮影スタジオの白ホリゾント（通称「白ホリ」）から取りました。「白い日」と読めることも掛けています。

予約サイトを題材に選んだのは、既存のサンプルに複数画面を持つものがECの1本しかなかったためです。サロン・治療院・スタジオ・レンタルスペースなど、予約が絡む店舗系のサイトには継続的な需要があります。

## 画面の流れ

```
トップ（施設紹介・料金・カレンダー）
  → 時間枠を選ぶ    ?v=slots&d=2026-09-22&r=A&h=9&n=2
  → 情報を入力      ?v=form&...
  → 内容の確認      ?v=confirm&...
  → 完了            ?v=done&...&c=HK-260922-2564
```

## 実装したこと

- **URL駆動のSPA**。画面・日付・部屋・開始時刻・利用時間をすべてクエリに持たせ、`pushState` / `popstate` で履歴と同期しています。ブラウザの戻るで1画面ずつ遡れ、URLを直接開けばその状態から始まります。部屋の切り替えや時間の変更は `replaceState` にして、履歴を汚しません
- **不正なURLの処理**。存在しない画面名、壊れた日付、未定義の部屋コードは、安全な画面に落とします（`?v=confirm&d=9999-99-99&r=Z` を開くとトップに戻ります）
- **カレンダー**。月送り、過去日の無効化、日ごとの空き状況を ○ △ × で表示。空き枠数は日付・部屋・時刻をハッシュした値から決めていて、何度開いても同じ結果になります。乱数にしないのは、リロードや戻る操作のたびに空き状況が変わると、選んだ枠が消えてURLも再現できなくなるためです。土日は埋まりやすく、たまに終日満室の日が出るようにしてあります
- **時間枠の選択**。予約済みの枠は押せません。開始時刻を選ぶと、そこから連続して取れる時間数だけが選択可能になり、選んだ範囲が枠上でハイライトされます
- **料金の自動計算**。部屋の単価 × 時間数に、オプション（照明セット、背景紙、撮影アシスタント）を加算します。アシスタントだけ時間あたりの課金なので、時間数を変えると金額が変わります
- **入力内容の保持**。確認画面から戻っても入力が消えません。`sessionStorage` に保存しています（`try` / `catch` で保護）
- **取った予約が空き状況に反映される**。サーバーがないため、完了した予約を `sessionStorage` に記録し、空き判定で参照しています。予約後に空き状況へ戻ると、その枠が「ご予約分」として埋まった状態で表示されます。ほかの予約済み枠とは見た目で区別しています。タブを閉じれば消えます
- **入力チェック**。氏名、電話番号（ハイフンなし10〜11桁）、メール形式、利用目的、同意チェックを検証し、該当項目だけを赤くして最初のエラー項目にフォーカスを移します
- **計測イベント**。`dataLayer` に `step_view`（画面名）、`date_select`、`slot_select`（部屋・時刻・時間数）、`option_change`、`form_error`、`cv_submit`（金額を含む）を送ります

## 画像について

写真素材を使っていません。部屋の見取り図、カメラのアイコン、完了画面のチェックマークまで、すべてSVGで作図しています。
