# 三崎精密工業 — 精密加工メーカーのコーポレートサイト

https://norio-io.github.io/samples/corporate/manufacturing/

架空の中小製造業のコーポレートサイトです。

## 題材と名前の由来

**三崎** は神奈川県三浦市の地名です。「地名＋業種」という、製造業の社名にありがちな型をそのまま使っています。実在の企業ではありません。

## 実装したこと

- **写真素材を一切使わない構成**。設備、加工精度、工程の図版をすべてSVGで作図しています。BtoBのコーポレートサイトは自社設備の写真が用意できないと作れないことが多いため、図版で成立させる形を試したものです
- **スクロールに応じた表示演出**
- 余白と図版で情報の階層を作り、文字量を抑えています
