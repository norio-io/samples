# 麦と焙煎 — カフェ＆ベーカリーの店舗サイト

https://norio-io.github.io/samples/store/cafe-bakery/

架空のカフェ＆ベーカリーの店舗サイトです。

## 題材と名前の由来

**麦と焙煎** は、パンの「麦」とコーヒーの「焙煎」を並べたものです。カフェとベーカリーという二本柱をそのまま名前にしています。

## 実装したこと

- **デザイン方向を2案切り替えられる実装**。画面右上のボタンで「ナチュラル」と「都会的」を切り替えます。店舗サイトではナチュラル系と都会的なテイストのいずれも需要があるため、両方を見せられる形にしました
- **縦書きのキャッチコピー**。`writing-mode: vertical-rl` を使い、スマートフォン幅では横書きに切り替えます
- **スマートフォンからの来店導線**を意識した画面設計
