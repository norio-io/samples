# ひとひ — 健康食品の定期購入ランディングページ

https://norio-io.github.io/samples/lp/supplement/

架空のブランド「ひとひ」の、広告流入を想定したランディングページです。商材は1日分ずつ個包装にした乳酸菌＋食物繊維のパウダー。

## 題材と名前の由来

**ひとひ** は「一日（ひとひ）」の古語読みです。1日分ずつ個包装という商品形式をそのまま名前にしました。ひらがな3文字で、毎日続けるものらしい柔らかさを狙っています。

健康食品を題材に選んだのは、LP制作では健康食品・サプリメント・美容・D2Cが主要な分野であり、これらの分野での実績が求められることが多いためです。

機能性表示食品にはしていません。架空の届出番号を書けないので、一般食品として組んでいます。効果効能を書けない制約のなかでどう売るかを見せる構成です。フッターに「本品は食品です。特定の保健の目的が期待できる旨の表示をしたものではありません」と明記しています。

## 画面構成

ファーストビュー → 悩み → 3つの特徴 → 1本の内訳 → 飲み方3ステップ → 利用者の声 → 料金 → 保証 → FAQ → 申し込みフォーム、の縦1枚。追従CTAを常時表示しています。

## 実装したこと

- **袋数で価格が切り替わる料金セクション**。1袋／2袋／3袋のボタンで、初回価格・割引率・1本あたりの単価・2回目以降の価格・追従CTAの文言が同時に変わります。フォームの袋数セレクトとも双方向に同期します
- **FAQのアコーディオン**。`details` / `summary` で、JavaScriptなしで開閉
- **入力チェック付きの申込フォーム**。氏名、メール形式、電話番号（ハイフンなし10〜11桁）、同意チェックを検証し、該当項目だけを赤く出して最初のエラー項目にフォーカスを移します
- **都度購入と定期便の比較表**
- **スクロールに応じた表示演出**。`IntersectionObserver` を使い、`prefers-reduced-motion` を指定している環境では無効化します
- **計測イベント**。`dataLayer` に `cv_click`（CTAの設置位置つき）、`plan_change`（選ばれた袋数つき）、`form_error`、`cv_submit`、`scroll_depth` を送ります。GTMのコンテナは入れていませんが、貼ればそのままトリガーに使えます

## 画像について

写真素材を一切使っていません。商品パッケージ、アイコン、成分の円グラフまで、すべてSVGで作図しています。無料素材で統一感のある商材写真を揃えるのが難しいことと、配色をページ全体と揃えられることが理由です。
