# ひのき学舎 — 学習塾のサイト

https://norio-io.github.io/samples/corporate/cram-school/

小学4年生から中学3年生を対象にした、架空の学習塾のサイトです。4ページ構成で、子どもの通塾を検討している保護者が、コース・料金・実績を比べながら確かめ、体験授業を申し込むまでの流れを組んでいます。

## 題材と名前の由来

**ひのき** は檜から取りました。幹がまっすぐ上へ伸びる木で、「まっすぐ伸びる」の意を屋号に込めています。ロゴも、まっすぐな幹に枝を3段重ねた檜の形にしています。**学舎** は、塾を「学ぶための建物」として呼ぶ古い言い方で、落ち着いた印象を保護者に向けて持たせるために選びました。

学習塾を選んだのは、対象学年ごとのコース、月謝と諸費用、合格実績、体験授業の申し込みという、比較して確かめる情報が多い業種であるためです。保護者は複数の塾を見比べるため、料金は月謝だけでなく年間の総額まで示すことが求められます。

## 画面構成

| パス | 内容 |
|---|---|
| `/` | キャッチコピーと体験授業の導線 → 学年から選ぶ入口（6学年） → 指導の特長3点 → 合格実績の抜粋 → 教室の案内と講師 |
| `courses/` | 学年のタブ（小4〜中3）。学年ごとにコースと授業の回数・時間・月謝の表、年間の総額の内訳の表 → 月謝と諸費用の考え方 |
| `results/` | 2024〜2026年春の進学先の一覧（高校・中学校）。架空の題材である旨と、数え方を明記 |
| `trial/` | 体験授業の申し込みフォーム（学年、希望のコース、希望日、保護者の連絡先） → 体験授業の流れ |

## 実装したこと

- **学年のタブ**。WAI-ARIA の tabs パターンに沿って `role="tablist"` / `tab` / `tabpanel` と `aria-selected` を与え、選択中のタブだけを Tab キーの移動先にしています（roving tabindex）。左右キーで隣の学年へ移り、端では反対側へ回ります。Home / End で先頭と末尾へ移ります
- **選択中の学年を URL のハッシュに反映**。`courses/#chu2` のように残すため、再読み込みや URL の共有で同じ学年が開きます。ハッシュの書き換えは `history.replaceState` で行い、タブを切り替えるたびに履歴が積み上がらないようにしています。`hashchange` も受け、トップの「学年から選ぶ」からのリンクでも該当の学年を開きます
- **年間の総額を JavaScript で算出**。各コースの行に月謝・教材費・春期・夏期・冬期講習費を `data` 属性で持たせ、そこから「月謝 × 12か月 ＋ 教材費 ＋ 季節講習費」を求めて内訳の表を組みます。金額は `Intl.NumberFormat` で桁区切りにします。金額の元を1か所に置くことで、表示と計算の食い違いを防いでいます
- **体験授業の希望日の検証**。日付の入力欄の `min` に当日を、`max` に2か月先を設定し、過去の日付をカレンダーで選べないようにしています。日付の入力欄は曜日単位で選択肢を消せないため、日を選んだ時点で曜日を確かめ、日曜日なら「日曜日は休校のため体験授業を行っていません」とその場で示します。送信時にも同じ判定を行います
- **フォームの検証**。必須項目の未入力、電話番号とメールアドレスの形式を送信前に確かめ、誤りのある項目に `aria-invalid` と項目ごとの文言を付けます。フォームの上に誤りの一覧を出してフォーカスを移し、一覧の各項目から該当の入力欄へ移れます。送信処理は持たず、正しく入力すると受け付けた内容をその場に表示します
- **コースのページから学年を引き継ぐ**。各学年の「体験授業を申し込む」は `trial/?grade=chu2` のように学年を渡し、フォームを開いた時点でその学年を選んだ状態にします
- **複数ページ構成**。ページごとにディレクトリを掘り、スタイルは `css/style.css` にまとめています。グローバルナビとパンくずの末尾に `aria-current="page"` を与えます

## 配色

瑠璃色（`#24399a`）を基調に、学習の印として黄（`#f3c623`）を差しています。黄は答案の丸、要点の下線、選択中のタブの上端など、「ここが大事」「できた」を示す箇所だけに使います。黄は文字色には使わず、黄の上の文字は濃紺、瑠璃の上の文字は白か黄としています。

瑠璃は紫寄りの青で、三崎精密工業の紺（`#0d4f8b`）とスタジオ白日の青（`#2563c9`）のどちらとも色相と明るさを離しています。

## 画像について

写真素材を使っていません。授業のようす、指導の特長、教室、講師はすべてインラインの SVG で描いています。グラデーションの背景や装飾だけの図形は置かず、図はいずれも内容（12席の教室、丸の付いた答案、仕切りのある自習席など）を表すものにしています。

## 表示の確認

幅 1755 / 1440 / 1024 / 768 / 390px と、本文のフォントサイズ 15px / 19px の組み合わせで、はみ出しとコントラスト（WCAG 2.1 SC 1.4.3 の 4.5:1）を確認しています。学年のタブは全6学年、フォームは誤りの表示と受け付けの表示の状態でも確認しています。

## 掲載内容について

塾名、氏名、料金、合格実績、学校名、所在地、電話番号は、すべてサンプル用に作成した架空のものです。実在の学校とは関係ありません。
