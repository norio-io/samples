# 山の湯宿 こだま — 旅館のWebサイト

https://norio-io.github.io/samples/store/ryokan/

架空の旅館のWebサイトです。客室、料理、温泉で滞在の魅力を伝え、空室と料金を確かめて予約へ進む、宿泊施設のサイトの標準形を4ページで組んでいます。

## 題材と名前の由来

**こだま**（木霊・谺）は、山や谷で声が反響して返ってくることです。屋号は「山あいに声が響き返す宿」の意で、谷あいの温泉地（架空の奥嶺町こだま谷）に建つ宿という設定に重ねています。ロゴは山の稜線と、そこから返る声の弧を描いたものです。客室名の「やまびこ」「ひびき」も同じ連想から付けています。

旅館を選んだのは、宿泊施設のサイトが「魅力を伝えるページ」と「空室と料金を確かめる画面」の両方を持ち、静的なページと動きのある画面の両方を見せられる題材であるためです。想定する閲覧者は、家族旅行や記念日の宿泊先を探している人です。

## 画面構成

| パス | 内容 |
|---|---|
| `/` | ヒーロー（キャッチコピーと空室の確認フォーム）→ 宿の特長3点 → 客室の抜粋3種 → 季節の料理と会席の流れ → 温泉 → 周辺の観光 → 交通 |
| `rooms/` | 絞り込み（人数・露天風呂）→ 客室の比較表 → 客室5種類の詳細（間取り図、広さ、定員、設備、1名あたりの料金の目安） |
| `calendar/` | 客室と人数の選択 → 月の空室カレンダー（前月・翌月へ移動）→ 選んだ日の合計額 |
| `access/` | 略図と送迎の案内 → 送迎の時刻表 → 館内の略図と施設の利用時間 |

## 配色

黒橡（くろつるばみ）の深い茶黒を基調に、金茶を差し色、生成（きなり）を地にしています。ヘッダー、ページ見出し、料理の節は黒橡の地に生成と金茶の文字で夜の山あいの静けさを、客室と温泉の節は生成の地で明るさを出しています。

| 役割 | 色 | 用途 |
|---|---|---|
| 黒橡 | `#2a231e` | 基調、本文の文字 |
| 金茶 | `#c9963f` | 黒橡の地の上の差し色 |
| 金茶（濃） | `#7f5617` | 生成の地の上の文字、休前日の印 |
| 生成 | `#f4eee1` | 地 |

文字に用いる組み合わせは、すべて WCAG 2.1 SC 1.4.3 の 4.5:1 を満たします（例: 黒橡の上の金茶 約5.8:1、生成の上の黒橡 約13.4:1、生成の上の濃い金茶 約5.6:1）。常磐法律事務所（白地 × 墨 × 臙脂）と違い、白ではなく生成を地とし、基調を茶みの黒にしています。

## 実装したこと

- **空室カレンダー**。架空のデータから描画します。空室は、客室と日付を種にしたハッシュ関数で決めるため、再読み込みしても、別の端末で開いても同じ結果になります。休前日と祝日は埋まりやすくしています
- **状態を記号と文字の両方で示す**。各日に「○ 空室」「△ 残りわずか」「× 満室」と1名あたりの料金を置きます。色だけに頼らず、記号と文字で区別できます
- **休前日の料金の区別**。休前日（土曜日と祝日の前日）は、日付の横の「休前日」の札、セル上端の金茶の線、料金の色で示し、1名4,000円を加算します。祝日は、日付の決まった祝日、第n月曜の祝日、振替休日を規則から求めています（春分・秋分の日は 3/20・9/23 に固定する簡略化をしています）
- **条件と月を URL に保持する**。`?room=yamabiko&guests=2&month=2026-11` の形で、客室・人数・月をクエリに持ちます。読み込み時に復元するため、再読み込みと URL の共有で同じ表示になります。月の移動は履歴に積み、ブラウザの戻るで前の月へ戻れます
- **不正なクエリの補正**。存在しない客室、数値でない人数、受付期間外の月は既定値に置き換え、その旨をカレンダーの上に表示します。人数が客室の定員を外れる場合は定員の範囲に収めます
- **受付期間**。今月から5か月先までを表示し、範囲の端では前月・翌月のボタンを無効にします。今日より前の日は「受付終了」とします
- **日付の選択**。空室のある日を選ぶと、選んだ人数での1名あたりの料金と合計額を表示します。予約の送信は行いません
- **狭い画面のカレンダー**。390px 幅では1セルが約50pxになるため、記号、状態（「残り／わずか」の2行）、料金を縦に積み、「円」を凡例に移して収めています
- **客室の絞り込み**。人数（定員の範囲に入るか）と露天風呂の有無で、比較表と詳細の両方を絞ります。条件に合う客室がない場合は、その旨と、どの条件を外せばよいかを示し、条件を解除するボタンを置きます。絞り込みの条件も URL に保持します
- **客室の比較表**。客室を行、広さ・定員・露天風呂・料金を列にした表です。`table-layout: fixed` と列幅の指定で、内容に幅が左右されないようにしています。狭い画面では表の枠の中で横に送れます
- **写真を使わない図版**。客室の間取り図、季節の料理（山菜の天ぷら、鮎の塩焼き、松茸の土瓶蒸し、牡丹鍋）、露天風呂、交通の略図、館内の略図まで、すべてインラインの SVG です。トップの料理の節では、閲覧した月の季節に「いまの季節」の印を付けます
- **複数ページの共通部品**。スタイルは `css/style.css`、客室と料金のデータは `js/data.js` にまとめ、客室ページとカレンダーの両方から読み込みます。現在のページはグローバルナビとパンくずに `aria-current="page"` で示します

## 掲載内容について

宿名、所在地、電話番号、料金、空室の状況、泉質の数値、送迎と列車の時刻は、すべてサンプル用に作成した架空のものです。
