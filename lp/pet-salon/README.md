# ドッグサロン こもれび — トリミングサロンの広告用ランディングページ

https://norio-io.github.io/samples/lp/pet-salon/

架空のトリミングサロン兼ペットホテルの、広告流入を想定したランディングページです。

## 題材と名前の由来

**こもれび**（木漏れ日）は、1頭ずつ完全個室で預かるという訴求に合わせた名前です。柔らかく、静かな印象を狙っています。

## 画面構成

ファーストビュー → 悩み → 3つのお約束 → 実績の数字 → 料金 → 当日の流れ → 利用者の声 → FAQ → 予約フォーム。追従CTAを常時表示しています。

## 実装したこと

- **入力チェック付きの予約フォーム**。氏名、電話番号（ハイフンなし10〜11桁）、メニュー選択、同意チェックを検証します
- **スクロールに応じた表示演出**（`IntersectionObserver` / `prefers-reduced-motion` 対応）
- **計測イベント**。`dataLayer` に `cv_click`、`form_error`、`cv_submit`、`scroll_depth` を送ります
- **送迎車・個室・写真送付の図版**をSVGで作図

## 画像について

ファーストビューの写真1枚（`img/hero.jpg`）だけ実写で、それ以外はSVGです。元画像を3:4に切り出し、900×1200にリサイズしたうえで、ページの配色に合わせて暖色寄りに補正しています。
