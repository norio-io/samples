# 石堂組 — 建設会社のコーポレートサイト

https://norio-io.github.io/samples/corporate/construction/

架空の総合建設会社（土木・建築）のコーポレートサイトです。

## 題材と名前の由来

**石堂組** は「石を積んで堂を建てる」の意。「◯◯組」は大林組、旧鹿島組など、建設業に古くからある社名の型です。実在の企業ではありません。

## 画面構成

事業内容 → 施工実績 → 数字 → 安全と品質の取り組み → 会社概要 → 採用 → お問い合わせ。

発注者（自治体・民間）と求職者の両方が来る想定で、施工実績と採用への導線を分けています。

## 実装したこと

- **施工実績のカテゴリ絞り込み**。土木／建築／リノベーション／維持管理の4分類で、JavaScriptで一覧を描き替えます。該当0件の場合の表示も用意しています
- **写真素材を一切使わない構成**。橋梁、校舎、工場、舗装などの実績図版を、図面のグリッドを敷いたSVGで作図しています
- **入力チェック付きの問い合わせフォーム**。必須5項目と同意チェックを送信時に検証し、該当項目を強調して最初のエラーにフォーカスを移します。入力を再開した項目からはエラー表示を外します
- スクロールに応じた表示演出（`prefers-reduced-motion` に対応）
